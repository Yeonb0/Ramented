# 라멘타쿠 화면 시안 재현 프롬프트

아래 텍스트를 그대로 복사해서 쓰면 이 시안과 동일한 결과물을 만들 수 있습니다.

---

라멘 지도 기록 앱 **라멘타쿠(Ramentaku)** 의 모바일 화면 시안 3개를 만들어줘. 390×844 프레임 3개를 가로로 나란히 놓고, 오른쪽에 마커 색 검수 패널을 하나 붙여줘.

## 제품 한 줄

지도에서 라멘 가게를 찾고, **특정 라멘을 파는 가게만 골라보고**, 인증샷과 라멘별 별점으로 나만의 라멘 지도를 채우는 앱. 평점은 가게가 아니라 **메뉴 하나**에 붙는다 — "이 가게 4.5"가 아니라 "이 가게의 돈코츠 4.5". 화면 어디서든 별점 옆에 메뉴명과 "이 메뉴의 별점" 라벨이 함께 읽혀야 한다.

## 아트 디렉션

- 아이보리 배경 + 쇼유 브라운. **납작한(flat) 일러스트 톤** — 게임 〈좋은 피자, 위대한 피자〉 같은 따뜻하고 만화적인 색감.
- 그림자 금지. 깊이는 **면 + 아웃라인**으로만 낸다. 모든 카드/박스 테두리는 `1.5px solid #CBB593`.
- 텍스처(사선 그레인, 노이즈) 금지. 색은 전부 단색 면.
- 모서리는 넉넉히 굴린다: 카드 14~20px, 기기 프레임 28px, 칩·토글은 999px.
- 화면 상단(상태바+헤더)과 하단(탭바)은 **진한 갈색 `#6A4729`** 단색. 내용과 맞닿는 쪽 모서리는 **직선**, 기기 모서리 쪽만 프레임 클립으로 둥글게. 바에 border-radius를 직접 주지 말 것.
- 갈색 바 위 요소는 반전: 텍스트/아이콘 크림 `#FDFAF4`, 보조 라벨 `#EFE0CC`, 라이트 칩 `#EFE0CC` + `#A2764C` 테두리, 반투명 칩 `rgba(253,250,244,0.18)` + `#EFE0CC` 테두리.
- 한글 폰트는 **나눔스퀘어라운드**(Naver 호스팅 웹폰트, R/B/EB 400·700·800). 자간 -0.2px.
- 흔한 "크림 배경 + 큰 세리프 헤드라인 + 테라코타 포인트" 조합으로 빠지지 말 것.

## 색 토큰 (이 값만 사용, 새 색 만들지 말 것)

```
bg #FDFAF4 · surface #F5EDDF · surfaceSunken #EFE5D3
border #E2D2B6 · borderStrong #CBB593
primary #B98B5E · primaryPressed #A2764C · primaryDark #7A5334 · primarySoft #EFE0CC
바 배경 #6A4729
text #3B2C21 · textSecondary #6B5642 · textMuted #9C8B79 · textOnPrimary #FDFAF4
star #D9963F · danger #B5503F
```

타입 스케일: caption 12/18 · footnote 13/20 · body 15/24 · subtitle 17/26 · title 20/30 · display 26/38.

## 지도 마커 규칙

색은 라멘 이름이 아니라 **타래 × 탁도** 조합으로 결정. 백탕 계열은 아이보리·회색 배경에서 흐려지므로 stroke를 반드시 넣는다(장식이 아니라 가독성 장치).

| 조합 | fill | stroke | mark | 해당 라멘 |
| --- | --- | --- | --- | --- |
| 시오 × 백탕 | #DBD0BA | #85694A | #5E4835 | 돈코츠 라멘 |
| 시오 × 청탕 | #6E9BB8 | #4F7A96 | #FDFAF4 | 시오 츠케멘 |
| 쇼유 × 백탕 | #E0CBA0 | #A9884E | #5E4835 | 토리파이탄 쇼유 |
| 쇼유 × 청탕 | #C08A2E | #96690F | #FDFAF4 | 마제소바 |
| 미소 × 백탕 | #D9B6A6 | #A9705A | #6E3A28 | 미소 라멘 |
| 미소 × 청탕 | #A8503A | #83381F | #FDFAF4 | — |

내부 마크는 **형태**로 라멘 종류를 구분: 라멘 = 원, 츠케멘 = 둥근 사각, 마제소바 = 마름모.
**필터가 없는 상태**에서는 한 가게가 여러 라멘을 팔기 때문에 색을 쓰지 않는다 — 중립 마커 `#A89078` / stroke `#85705A` 에 취급 라멘 수를 작은 배지로 얹는다.

## 화면

**① 지도 홈 — 돈코츠 라멘 선택 상태 (핵심 화면)**
갈색 헤더에 로고 + "라멘 지도" + "가게 검색" 필 버튼. 그 아래 라멘 종류 칩이 가로 스크롤(오른쪽 칩이 살짝 잘려 보이게), "돈코츠 라멘"이 선택 상태(크림 솔리드 + 해제 ×). 칩마다 해당 라멘의 마커 색 점을 붙여 지도와 매칭시킨다.
지도는 카카오맵 자리 — 회색빛 타일(#EAE6DE 격자), 밝은 도로 띠, 공원(#E1E6D8)·한강(#DDE4E8) 패치로 대충 그린다. 마커와 위에 얹히는 UI가 본론.
돈코츠를 파는 두 곳(멘야 산다이메, 하카타 분코)만 시오×백탕 마커로 남고, 필터로 빠진 가게는 점선 회색 원으로 흐리게. 선택된 마커는 44px + 이름·★4.7 라벨, 나머지는 36px + 이름 라벨.
지도 왼쪽 위에 "전문점만" 토글(off), 오른쪽 위에 내 위치 버튼.
하단 바텀시트(surface, 위쪽만 20px 라운드): 드래그 핸들, "돈코츠 라멘 파는 곳 2" + "별점 높은 순", 그리고 결과 카드 2장. 카드는 인증샷 썸네일 + 가게명 + 거리·지역 + **메뉴 블록**(#EFE0CC 면에 "이 메뉴의 별점" 캡션 / "특제 돈코츠 · 10,000원" / ★4.7 (34))로 구성.

**② 가게 상세 — 하카타 분코**
갈색 헤더에 뒤로가기 원형 버튼 + "저장"(반투명) + "기록 남기기"(크림 솔리드, 갈색 글자).
가게명 앞에 중립 마커 + 취급 수 배지 "2". 태그 칩 "돈코츠 · 미소 2종", "방문 3회". 정보 카드에 주소 / 영업 11:30~22:00 + 브레이크타임 15:00~17:00(danger 색으로 강조).
"취급 라멘 2" 섹션 — 카드마다 마커 스와치(색+형태) + 메뉴명 + 가격·"시오 × 백탕" + 오른쪽에 큰 별점(24px, star 색) + 리뷰 수. 하카타 돈코츠 4.6 / 미소 라멘 4.2로 같은 가게 안에서도 갈리는 게 보이게.
"인증샷" 섹션 — 메뉴 태그 칩("하카타 돈코츠")을 제목 옆에 붙이고, 리뷰 2개(줄무늬 플레이스홀더 썸네일 + 닉네임 + ★ + 짧은 실사용 코멘트 + 방문 날짜).

**③ 프로필 — 이번 주 등급**
최근 7일 방문 횟수로 등급이 정해지고 아바타 **테두리 링**으로 표현된다. 매주 리셋되므로 "이번 주 등급 (7.20~7.26)"처럼 기간을 명시.
등급: 라이트 라멘러 0~1회 / 라멘 애호가 2~4회 / 주간 라멘왕 5회 이상. 시안은 "라멘 애호가", 최근 7일 3회, 링 색 #B98B5E.
갈색 상단 바에 "내 라멘 기록" + 설정 버튼. 등급 카드에 아바타 링 + 등급명(24px, #7A5334) + 3회 방문 + 3단 진행 바(60%) + "2번 더 가면 이번 주 라멘왕. 등급은 매주 월요일에 다시 계산돼요."
취향 리포트: 라멘 종류별 막대(돈코츠 12 / 토리파이탄 쇼유 7 / 미소 5 / 시오 츠케멘 4 / 마제소바 2, 각 행 앞에 마커 색·형태 스와치), 지역별 타일(마포구 18 / 용산구 6 / 그 외 6) + "가장 자주 간 곳 · 멘야 산다이메 5회".

**마커 검수 패널** — 6색 스와치를 fill/stroke 헥사와 함께 나열하고, 중립 마커도 한 줄. 아래에 백탕 3색(#DBD0BA / #E0CBA0 / #D9B6A6)을 나란히 두어 아이보리 위 구분도를 눈으로 검수할 수 있게.

## 하지 말 것

- 카드마다 드롭섀도 — 이 톤에서 제일 먼저 어색해진다
- 라멘 사진을 크게 깔아 분위기 내기 (실제 앱엔 유저 인증샷뿐, 전부 줄무늬 플레이스홀더 + 모노스페이스 라벨)
- 이모지를 아이콘 대신 쓰기 (아이콘은 원·둥근 사각·마름모 같은 단순 도형으로)
- 채도 높은 포인트 컬러 추가, 토큰 밖의 새 색
- 탭바/헤더에 라운드 주기, 사선 그레인·노이즈 텍스처

# Phase 1 — 시드 30곳 공공데이터 좌표 매칭 결과

> PHASE1_CONTEXT 백엔드 3번의 기록. 좌표 · 주소 출처는 shaping U4 결정대로 공공데이터만 쓴다

## 출처

- 공공데이터포털 "행정안전부_식품_일반음식점" (관리자님이 2026-11-13 내려받아 전달). 마포구 (`3130000`) 30,168행, 서대문구 (`3120000`) 18,407행
- 좌표계 : 보정계수 없는 Bessel 중부원점 TM (EPSG:5174) → WGS84 변환 (pyproj, `+towgs84=-115.80,474.99,674.11,1.16,-2.31,-1.63,6.43`)
- 대상 : `영업상태명` 이 "영업/정상" 인 11,356곳

## 매칭 방법

1. 시드 이름 (지점명 제외) 을 공백 · 괄호를 뺀 소문자로 바꿔 사업장명에 포함되는지 본다
2. 후보가 여러 곳이면 동네 (seed-survey 지역) 로 고른다
3. 30곳 모두 마포구 파일에서 찾았다. 서대문구 파일에서 고른 곳은 없다

# 시드 후보 30곳 조사 (v1 시드 목록 기준)

## 조사 방법

- 조사일 : 2026-11-12
- 출처 : 카카오맵 가게 페이지 (place.map.kakao.com) 를 한 곳씩 열어 읽음 (Claude in Chrome)
- 가져온 것 : 가게 이름, 카카오 장소 ID, 요일별 영업시간, 등록된 메뉴 이름 · 가격, 인스타그램 계정
- 가져오지 않은 것 : 사진, 후기, 소개 문구, 주소 · 좌표 (주소 · 좌표는 shaping U4 결정에 따라 공공데이터에서 가져온다)
- 대상 : v1 시드 (`seed_mapo_ramen_v2.sql`) 의 30곳

## 읽을 때 주의

- 영업시간은 카카오맵이 2026-11-12 ~ 11-18 한 주에 대해 보여준 값이다. 임시 변경이 섞여 있을 수 있다 (라멘야누는 "임시영업시간"이라고 표시됨)
- 메뉴는 카카오맵에 등록된 것만이다. 가게가 등록하지 않았거나 오래된 메뉴가 있을 수 있다
- **국물 속성 (해산물 포함 여부, 청탕 / 백탕) 은 이 조사로 확정하지 않았다.** 메뉴 이름만으로 속성을 정하지 않는다는 원칙에 따라, 아래 표에는 메뉴 이름과 가격만 적는다
- 사이드 · 음료 · 토핑 · 세트는 표에서 뺐다

## 메뉴 보충 (2026-11-13)

- 네이버 지도는 Claude in Chrome에서 접근이 막혀 있어 (확장 프로그램의 사이트 제한) 확인하지 못했다
- 대신 뽈레 (polle.com) 가게 페이지의 메뉴 목록을 읽었다. 뽈레는 사용자 참여형 서비스라 **메뉴가 언제 등록됐는지 알 수 없다**. 시드 전에 가게 인스타 또는 방문으로 한 번 더 확인한다
- 무겐스위치 : 뽈레 후기에 리모델링 후 재오픈 언급, "매운이에케라멘" 언급이 있어 메뉴 이름이 바뀌었을 수 있다
- 부탄츄 홍대점 : 국물 (톤코츠 / 토코 톤코츠) × 소스 (쇼유 / 시오) 조합 4종에 면 · 토핑을 고르는 방식. 금 · 토 심야에는 주간 한정 라멘이 따로 있다는 후기가 있다

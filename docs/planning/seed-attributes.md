# 시드 30곳 메뉴별 국물 속성 조사

## 조사 방법

- 조사일 : 2026-11-13
- 대상 : `seed-survey.md` 의 확정 30곳, 라멘 메뉴만 (사이드 · 음료 · 덮밥 제외)
- 확인 순서 (shaping 결정 2026-11-13) : 가게 인스타 → 메뉴판 → 가게 설명. 확인되지 않은 값은 "모름"
- 실제로 쓸 수 있었던 근거 :
  - **가게 인스타 : 쓰지 못함.** 로그인하지 않으면 게시물을 볼 수 없다 (로그인 창이 뜸)
  - **카카오맵 메뉴 설명 : 사용.** 메뉴 이름 아래의 설명 문장 (`desc_item2`)
  - 카카오맵 메뉴 아래의 키워드 칩 ("시원하고 깔끔한 국물" 같은 것) 과 "kanana 장소요약"은 리뷰를 요약한 AI 문구이므로 쓰지 않았다
- 판정 규칙 :
  - 메뉴 이름만으로 정하지 않는다. 이름에 담긴 힌트 (파이탄, 니보시, 교카이 등) 는 "이름 힌트" 칸에만 적는다
  - **해산물 "포함"** : 설명에 해산물 재료가 육수 · 타레 · 소스 · 토핑으로 적혀 있을 때
  - **해산물 "미포함"** : 설명에 해산물이 없다는 것만으로는 미포함으로 적지 않는다 (아래 "중요한 발견" 참조)
  - **청탕** : 설명에 "맑은", "청탕", "투명한"이 있을 때
  - **백탕** : 설명에 "뽀얀", "크리미한", "백탕"이 있을 때
  - **백탕\*** : 설명에 "돈코츠"가 육수 종류로 적혀 있을 때. 돈코츠는 거의 항상 백탕이지만 추론이 들어가므로 따로 표시한다 (관리자님 확인 필요)
  - **해당 없음** : 설명에 "국물 없는", "비빔면", "비벼 먹는"이 있을 때 (마제소바 · 아부라소바)
  - "진한", "깔끔한", "담백한"은 청탕 / 백탕 어느 쪽에도 쓰이므로 근거로 쓰지 않았다

## 중요한 발견

1. **해산물 "미포함"으로 확인된 메뉴가 0개다.** 카카오맵 설명은 재료를 다 적지 않는다. 예 : 니시무라멘의 "교카이파이탄" (교카이 = 어패류) 설명은 "닭뼈 육수에 김 오일"뿐이라 해산물이 빠져 있다. 그래서 설명에 해산물이 없다고 미포함으로 적으면 틀린 값이 들어간다
   - 결과 : 시드 시점에는 "해산물 제외" 필터가 걸러낼 수 있는 것이 "포함" 확인된 메뉴뿐이고, 나머지는 전부 "모름"이다. breadboard에서 정할 "모름 메뉴를 필터에서 보일지 숨길지"가 첫 사용 경험을 좌우한다 (숨기면 지도가 거의 빈다)
2. **카카오맵 설명의 작성자를 확인할 수 없다.** 사장님이 쓴 것 (오타 · 고유 표현이 있음 : 사루카메, 시카메이, 멘야호타루) 과 카카오 쪽에서 정리한 것으로 보이는 문장 ("~가 올라간 라멘" 형식) 이 섞여 있다. 근거 이름을 "카카오맵 메뉴 설명"으로 통일하고 확신도는 낮게 둔다
3. 메뉴판 사진은 이번에 읽지 않았다. 사진에 원재료가 적힌 가게가 있으면 "모름"을 줄일 수 있다

## 관리자님 결정이 필요한 것

1. **"돈코츠" → 백탕 추론을 받아들일지** : 받아들이면 백탕\* 10개가 백탕이 된다. 같은 기준으로 설명에 "돼지뼈 육수"만 있는 메뉴 (하쿠텐 이에케, 산다이메 돈코츠 등) 는 그대로 모름
2. **다시마 (곤부) 를 해산물로 볼지** : 해산물 육수를 싫어하는 이유가 생선 · 조개 풍미라면 다시마는 빼는 것이 자연스럽다. 해당 메뉴 : 라멘롱시즌 곤부스이츠케멘 (시카메이 토리쇼유는 부시도 있어서 어느 쪽이든 포함)
3. **라멘이 아닌 메뉴** : 천하일면의 고기국수 2종을 시드에서 뺄지
4. **이름 힌트를 시드에 쓸지** : 지금 규칙은 "메뉴 이름만으로 정하지 않는다"이다. 다만 "파이탄", "마제소바", "시루나시"처럼 이름 자체가 국물 종류를 뜻하는 경우가 있다. 이 원칙은 앱이 이름 문자열을 파싱하지 않는다는 것이었으므로, 운영자가 시드를 만들 때 이름을 근거로 쓰는 것은 별개로 판단할 수 있다
   - 쓰면 : 국물 "모름"이 크게 줄어든다. 근거는 "메뉴 이름"으로 남기고 확신도를 낮게 둔다
   - 안 쓰면 : 지금 표 그대로 시드하고 방문자 태깅으로 채운다
5. **"모름"을 줄일 다음 수단** : 관리자님이 인스타에 로그인된 Chrome을 쓰시면 인스타 확인이 가능하다. 또는 메뉴판 사진을 읽는 방법이 있다 (가게당 시간이 더 든다)
